# מפת ההכשרה — המחלקה לפוליטיקה וממשל

דשבורד המציג את תהליך ההכשרה: מה נלמד מתי, אילו מיומנויות מפותחות, והיכן הפערים.

## שלושת הקבצים

- **`index.html`** — הדשבורד. כמעט לעולם אינו משתנה.
- **`courses.csv`** — שורה לכל קורס. שם, שנה, סמסטר, סטטוס, מבנה הערכה.
- **`tasks.csv`** — שורה לכל מטלה. מקושרת לקורס דרך `course_id`.

## איך מוסיפים

**קורס חדש** (כולל קורס בחירה): הוסף שורה ל-`courses.csv`. הוא יופיע מיד בדשבורד — גם אם אין לו מטלות, כשורה מסומנת.

**מטלה חדשה**: הוסף שורה ל-`tasks.csv`. השורה מגיעה מוכנה מפרויקט הניתוח.

## איך מעדכנים בפועל

1. לחץ על הקובץ הרצוי (`courses.csv` או `tasks.csv`)
2. לחץ על סמל העיפרון (עריכה)
3. הדבק את השורה החדשה בסוף
4. לחץ `Commit changes`

הדשבורד מתעדכן תוך דקה.

## פורמט

רשימות מרובות ערכים מופרדות בקו אנכי, למשל:
`ניתוח מקורות | הבנה מושגית | כתיבה אקדמית`

## הערת פרטיות

הדשבורד אינו מכיל שמות מרצים. **אין להעלות למאגר זה** את קבצי המטלות המקוריים או את קובץ הקישור עם שמות המרצים — אלה נשארים בדרייב הפרטי.
